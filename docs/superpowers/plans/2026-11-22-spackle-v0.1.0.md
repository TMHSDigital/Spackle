# Spackle v0.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Spackle v0.1.0: an agentic security and debugging CLI that finds flaws, proves them in a sandbox, explains exploitation, and fixes them, in a public repo that is finished on first push.

**Architecture:** A staged pipeline (mapper, seeders, planner, investigators, prover, reviewer, fixer) with typed hand-offs. Every event is appended to a JSONL ledger and reports are a pure function of the ledger. Scope, budgets and tool permissions are enforced in Go, never by prompt.

**Tech Stack:** Go (min 1.26, latest 1.27), stdlib `flag`/`net/http`/`html/template`, `BurntSushi/toml`, `go.yaml.in/yaml/v3`, `pandatix/go-cvss`. Docker or Podman CLI for the sandbox. GitHub Actions, goreleaser, cosign, syft.

**Spec:** `docs/superpowers/specs/2026-11-22-spackle-design.md` (and the build prompt it implements).

## Global Constraints

- Module path `github.com/TMHSDigital/spackle`; binary `spackle`; `CGO_ENABLED=0`.
- `go.mod` says `go 1.26`; CI matrix is Go 1.26 and 1.27 on ubuntu, macos, windows.
- CI needs no API key and no container runtime except the Linux Docker integration job.
- No `net.Listen`, `http.ListenAndServe` or `http.Server` in non-test code.
- API keys come from environment variables only, never flags or config values.
- All prose: no em dashes, no emojis, no marketing words, no claims about unbuilt features.
- Every GitHub Action pinned to a full commit SHA; workflows have top-level `permissions: read-all`.
- Conventional commits; each milestone ends with a CHANGELOG entry, a commit, and a green CI run.
- Error messages state what happened, why, and what to do next.
- Line endings LF in the repo; `*.ps1` CRLF. Paths handled with `filepath`; ledger and reports store forward-slash relative paths.

## Review Focus

1. A target path with spaces, a drive-letter root, or CRLF source files: locations and quoted lines must still be exact. Test in `mapper` and `seed` (Task 4, 5).
2. A target containing text that imitates envelope delimiters or tool-result framing: content stays inside the envelope and no tool argument escapes scope. Test in `envelope` and `agent/tools` (Task 9, 11).
3. A model that returns malformed JSON, an unknown tool, a path outside the target, or a quote that is not in the file: the draft is rejected with a ledger event, the run continues. Test in `agent` (Task 11).
4. A scope file allowing `example.test` and a server that redirects to another host: the redirect is refused and logged. Test in `dast` (Task 15).
5. A huge or binary file, a symlink leaving the target root, or an unreadable directory: skipped with a note, no crash, no read outside root. Test in `mapper` (Task 4).

## Interfaces shared across tasks

```go
// internal/ledger
type Event struct { Seq int64; TS time.Time; Parent int64; Type string; Data json.RawMessage }

func Read(dir string) ([]Event, error)

// internal/finding
type Finding struct { /* fields listed in the spec, JSON snake_case */ }
func (f *Finding) Validate() error
func Score(vector string) (score float64, label string, err error) // CVSS 4.0
func Rank(fs []Finding) []Finding                                    // score desc, then id

// internal/seed

    File string; Line, EndLine int; Endpoint, Param string; Snippet, Detail string }
type Seeder interface { Name() string; Available() (bool, string); Run(ctx context.Context, root string) ([]Lead, error) }

// internal/llm
type Provider interface { Name() string; Complete(ctx context.Context, req Request) (Response, error) }
type Request struct { Model, System string; Messages []Message; Tools []ToolDef; MaxTokens int }
type Response struct { Text string; ToolCalls []ToolCall; Usage Usage; StopReason string }
type Usage struct { InputTokens, OutputTokens int; Estimated bool; CostUSD float64; CostKnown bool }

// internal/budget
type Caps struct { Tokens int; USD float64; Wall time.Duration; SandboxRuns, Findings int }
func (b *Budget) Charge(u llm.Usage) error   // returns ErrExhausted when a cap is passed
func (b *Budget) Allow(kind string) error

// internal/authz
type Scope struct { Hosts []string; Ports []int; PathPrefixes []string; AllowUnsafeMethods bool }
type Grant struct{ /* unexported; only Gate returns one */ }
func Gate(target string, opts Options) (*Grant, error)
func (g *Grant) Permits(u *url.URL, method string) error

// internal/sandbox
type Profile struct { Network string; MemoryMB int; CPUs float64; PIDs int; Timeout time.Duration }
type Result struct { ExitCode int; Stdout, Stderr string; TimedOut bool; Profile Profile; Argv []string }
type Runtime interface { Name() string; Run(ctx context.Context, spec Spec) (Result, error) }
func Detect() (Runtime, error)   // ErrNoRuntime when neither docker nor podman works

// internal/report
func Render(format string, run Run, w io.Writer) error // terminal|markdown|html|json|sarif
func Load(runDir string) (Run, error)                  // from ledger only
```

### Task 3: Finding schema and CVSS
**Files:** `internal/finding/{finding.go,cvss.go,rank.go,*_test.go}`.
- [ ] Tests: `Score("CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:N/VC:H/VI:H/VA:H/SC:N/SI:N/SA:N")` returns 9.3 "critical"; invalid vector errors; `Validate` rejects missing location, unknown confidence, proof `demonstrated` without an artifact; `Rank` is stable.

### Task 4: Target and mapper
**Files:** `internal/target/target.go`, `internal/mapper/{mapper.go,detect.go,cache.go,*_test.go}`, `internal/gitx/gitx.go`.
- [ ] `target.Classify(arg string) (Kind, error)` with `KindPath|KindGit|KindURL`; `http(s)://host/x.git` and `git@` are Git, other `http(s)` are URL.
- [ ] `mapper.Map(ctx, root) (Map, error)`: languages by extension, frameworks by manifest and import, entry points (HTTP handlers, `main`, CLI), test and build commands, infra files. Skips `.git`, `node_modules`, `vendor`, files over 1 MiB, binaries, and symlinks resolving outside root (Review Focus 1 and 5).
- [ ] Cache at `.spackle/cache/map-<sha>.json` when the tree is clean.

### Task 5: Redaction and built-in seeders
**Files:** `internal/redact/{redact.go,rules.go,*_test.go}`, `internal/seed/{seed.go,code_rules.go,secrets.go,docker.go,k8s.go,terraform.go,workflow.go,external.go,*_test.go}`.
- [ ] `redact.Scan(text) []Match` and `redact.Apply(text) (string, []Match)`; replacement is `[REDACTED:<rule>:<8 hex of sha256>]`. Rules: AWS keys, GitHub and GitLab tokens, Slack, Stripe, Google API, private key blocks, JWTs, generic `password|secret|token|api_key = "..."` with an entropy floor.
- [ ] Built-in code rules for Go, Python, JS/TS: SQL built by concatenation or formatting, command execution with dynamic input, path traversal, SSRF sinks, unsafe deserialization, weak crypto and hashing, disabled TLS verification, `eval`, template injection, hardcoded credentials, permissive CORS, JWT `none` or unverified decode, insecure randomness for tokens, debug mode.
- [ ] Infra rules: Dockerfile (root user, `latest`, `ADD` URL, secrets in `ENV`, curl-pipe-shell), Kubernetes (privileged, hostNetwork, hostPath, missing limits, `allowPrivilegeEscalation`), Terraform (public S3, `0.0.0.0/0` on admin ports, unencrypted storage), workflows (`pull_request_target` with checkout of head, unpinned actions, script injection from `github.event`, write-all permissions).
- [ ] External adapters parse JSON output from Semgrep, gitleaks, osv-scanner, Trivy, hadolint; gitleaks output is run with redaction so values never enter leads.
- [ ] Test: a secret lead never contains the secret value.

### Task 6: Reports
**Files:** `internal/report/{load.go,terminal.go,markdown.go,html.go,json.go,sarif.go,report_test.go}`, `internal/report/testdata/golden/*`.
- [ ] Golden test per format from one fixed ledger; `-update` flag rewrites. Rendering twice yields identical bytes. SARIF validates structurally (version `2.1.0`, `runs[0].tool.driver.rules`, `results[].locations`), severities mapped to `security-severity`.

### Task 7: `scan` (no LLM), `report`, `doctor`
**Files:** `internal/config/{config.go,config_test.go}`, `internal/engine/{engine.go,engine_test.go}`, `internal/cli/{scan.go,report.go,doctor.go}`, `examples/demo-app/`.
- [ ] `engine.Run(ctx, Options) (runID string, err error)` drives stages and writes the ledger; leads become findings with confidence `plausible`, proof `not-run`.
- [ ] `doctor` reports runtime, each scanner, provider config and a provider round-trip; exits non-zero only on misconfiguration, not on missing optional tools.
- [ ] End-to-end test: scan `examples/demo-app`, expect at least SQL injection, command injection, hardcoded secret; all five formats written.

### Task 13: Prover, fixer, worktree, `verify`
**Files:** `internal/agent/{prover.go,fixer.go}`, `internal/gitx/worktree.go`, `internal/cli/verify.go`, tests.
- [ ] Prover: model writes a PoC file set plus a run command and a success marker; engine runs it; marker in output promotes to `demonstrated`. No runtime leaves proof `not-run`.

- [ ] `verify <run-id>` re-runs stored PoCs and appends verdict events.
